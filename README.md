

# Team Prototype

A team prototype with FastAPI, PostgreSQL, a RAG knowledge module, and a fine-tuned Qwen-based response module.

## Repository layout

- `backend/` — FastAPI application, services, schemas, and tests
- `database/` — SQL schema, migrations, and synthetic seed data
- `shared/` — Contracts shared across team members

## Current status

Phase 1 scaffold created.

Start with `backend/README.md` for instructions to install dependencies, run the API, and execute the health-check test.

## Data and security

Use synthetic demo data only. Do not add real banking customer data or credentials to this repository.
